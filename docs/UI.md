# UI brief (for the UI review agent)

**Who:** Magic: The Gathering players of every skill level, on phone and desktop, who know cards but not our app or Scryfall syntax. They search for a card, look at it, add it to a deck, and maybe buy it.
**Protect:** search speed and the plain search box; the card page; deck import/export; affiliate buy links (never Scryfall's ids); no paywalls, upsells or ads.
**Look for:** filters and advanced syntax shown before they are needed; two places to do the same deck action (deck page vs card page vs list); deck-building jargon without a hint; empty and error states that don't say what to try next.
**Careful:** the plan's Not-doing list (simple search mode, First/Last page buttons). Removing a feature is hold: true.
